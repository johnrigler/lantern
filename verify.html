Lantern Evidence Verifier V1

Runs locally in your browser. No upload, backend, wallet, or blockchain connection. Verifies canonical JSON bytes and SHA-256, not whether a game was completed.

Waiting for evidence.

Canonicalization uses a restricted RFC 8785-compatible JSON subset: safe integer numbers only, no floating-point values; duplicate object keys rejected; UTF-8 and lexicographic UTF-16 key ordering. This verifier rejects unsupported types and malformed Unicode. The digest excludes any detached expected hash.
